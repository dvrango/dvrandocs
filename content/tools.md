# 🛠️ Setup Inicial: Herramientas Necesarias

¡Bienvenido al equipo! Para poder "chambear" cómodamente y seguir el ritmo del laboratorio, necesitamos que tengas instalado y configurado el siguiente set de herramientas.

Por favor, asegúrate de ir marcando el checklist conforme las tengas listas.

### Desarrollo Core

El entorno base para escribir código.

- [ ] **Visual Studio Code (VS Code)**: Nuestro editor de texto preferido. Te recomendamos buscar extensiones útiles para JS/TS.
- [ ] **Git**: Indispensable para el control de versiones y colaboración.
- [ ] **NVM (Node Version Manager)**: Vital para cambiar entre versiones de Node.js dependiendo del proyecto en el que estés trabajando.

### Asistentes de IA & Potenciadores

En DvranLabs la IA es parte de nuestro flujo diario para ser más eficientes.

- [ ] **Gemini CLI**: Para acceso rápido a Gemini desde la terminal.
- [ ] **Claude Code**: Asistente de codificación.
- [ ] **ChatGPT**: Para consultas generales, brainstorming y apoyo.
- [ ] **Gemini (Web)**: El modelo multimodal de Google.
- [ ] **Antigravity Google**: (Herramienta interna/específica del lab).

### Organización y Comunicación

Cómo nos mantenemos sincronizados.

- [ ] **Obsidian**: Nuestro cerebro digital para documentación, notas técnicas y gestión de conocimiento.
- [ ] **Discord**: El centro de comunicación diaria del equipo (chats rápidos, llamadas de voz).
- [ ] **ClickUp**: Nuestra plataforma para gestión de proyectos, tareas y sprints.

---

Cuando tengas todo listo, avísanos en el canal de Discord #onboarding para hacer una revisión rápida y asegurarnos de que estás listo para comenzar a contribuir al laboratorio.
